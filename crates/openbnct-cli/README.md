# openbnct-cli

The `openbnct` command-line interface for
[OpenBNCT](https://github.com/AvilaLabs/OpenBNCT): case and manifest
inspection, OpenMC deck generation/execution/collection, acceptance
evaluation, variance-reduction resolution and validation, biological and
endpoint modeling, boron fields, registration, systematic uncertainty, DICOM
import/export, and evidence tooling. See `docs/USAGE.md` in the repository.

Research software — no clinical, commissioning, or regulatory qualification.
