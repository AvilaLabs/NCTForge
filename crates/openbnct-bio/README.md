# openbnct-bio

Separately versioned biological dose interpretation for
[OpenBNCT](https://github.com/AvilaLabs/OpenBNCT): CBE/RBE models
(`openbnct.biological-model`), BED/EQD2 and combined-dose bundles, endpoint
models and evaluations (TCP/NTCP-style scoring), microdosimetric MKM-family
models with lineal-energy spectra, and bio-sensitivity sweeps. Every biological
result binds the exact physical bundle, boron field, and parameter set by
content hash.

Research software — biological models are declared assumptions, not clinical
calibrations.
