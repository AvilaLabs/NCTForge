# openbnct-evidence

Evidence and QA layer for
[OpenBNCT](https://github.com/AvilaLabs/OpenBNCT): evidence-bundle manifests,
dose metrics and dose-volume histograms over voxel masks, dose comparisons
(gamma/agreement), irradiation-time reports, and the bounded qualification
vocabulary every OpenBNCT artifact must declare.

Research software — qualification states describe evidence, never clinical
fitness.
