# openbnct-njoy

Deterministic NJOY response-generation adapter for
[OpenBNCT](https://github.com/AvilaLabs/OpenBNCT). Produces input manifests,
executes pinned NJOY2016 runs under a controlled receipt, and generates
verified neutron response sets with transported-photon suitability,
domain-aware assessment, energy-balance attribution, and candidate-comparison
contracts — all hash-bound to evaluated-data provenance.

Research software — response sets are benchmark evidence for declared
component semantics.
