# Response-treatment candidates

This directory preserves alternate evaluated-data investigations without
changing the `NF-BNCT-001` baseline. Every candidate must bind a publisher
artifact, the exact ten-nuclide selection, the unchanged material, a matching
response-generation method, controlled processor evidence, and a deterministic
comparison with the rejected baseline.

A candidate result can clear a narrow mechanical gate only as
`candidate_mechanical_gate_clear_unreviewed`. No comparison artifact can grant
scientific approval or make a table reviewable by itself.
